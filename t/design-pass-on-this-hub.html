Design pass on this hub

Anthropic's design plugin run on this page: critique, accessibility, UX copy, design system. What it found and what changed.

We ran Anthropic's design plugin for Claude on this hub: design critique, UX copy, accessibility review (WCAG 2.1 AA) and design system. Content and links stayed exactly as they were. This is what it found and what changed.

Critique

  • First look: the headline, search and the "just in" strip read in the right order. The dark, grainy, editorial look works, so it stays.
  • Usability: search, type filters and section jumps already cover the main job (find a thing fast). Kept.
  • Weak spots: filter buttons, section chips and small links were too small to tap cleanly on a phone, and control outlines almost disappeared on the dark background.

Accessibility (WCAG 2.1 AA)

  • 1.4.11 non-text contrast: the search box and filter buttons had outlines at 1.3:1. Now 3.8:1 or better.
  • 2.5.5 touch targets: every button and chip is now at least 44px tall: filters, section jumps, play, download, clear, close, and prev/next.
  • 2.4.1 bypass blocks: added a "skip to content" link, visible on keyboard focus.
  • 1.3.1 structure: "just in" is now a real heading, read pages go h1 to h2 without skipping a level, and the footer is a real footer landmark.
  • 2.4.4 link purpose: "open full" links now announce that they open a new tab.
  • Text contrast: already passing (6.2:1 to 15.9:1), unchanged.
  • Reduced motion: card hover lift and poster zoom are off when your device asks for less motion.

UX copy

  • The "press / to search" hint is keyboard only, so it's hidden on phones.
  • CTAs already start with a verb (read, play here, download, open) and the empty state says what happened and how to get out of it. Kept.

Design system

  • Added tokens for spacing (4px scale), type scale (12 / 15 / 17 / 21 / 26), tap size (44px) and a control edge colour.
  • Smallest text raised from 11px to 12px across labels, dates and meta lines.
  • Card titles, card lines and section blurbs now use the same type scale everywhere.

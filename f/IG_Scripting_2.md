# The REAL Viral Strategy

Virality starts BEFORE writing.

Do not think:

* “What do I want to say?”

Think:

* “What emotion makes people stop scrolling?”

Audience psychology > creativity.

# Viral Stack Method (MOST IMPORTANT)

The highest-performing reels stack multiple viral triggers together.

## Formula:

### Trend + Controversy

Example:
“Why everyone using AI agents right now is making a huge mistake.”

---

### News + New Perspective

Example:
“OpenAI didn’t launch this feature to help users. They launched it to kill SaaS startups.”

---

### Relatable + Fear

Example:
“Every AI engineer secretly feels behind right now.”

---

### Mass Query + Contrarian Answer

Example:
“Why learning to code might actually hurt your AI career in 2026.”

---

### Mind-Blowing + Hidden Connection

Example:
“This McDonald’s system uses the same psychology as TikTok addiction.”

# How To Generate Viral Ideas

Ask these:

* What is everyone talking about?
* What is nobody saying about it?
* What hidden consequence exists?
* What fear exists underneath?
* What surprising comparison can I make?
* What belief can I attack?
* What truth sounds illegal to say?

# Script Structure

## 1. Hook

Create confusion, fear, curiosity, or surprise.

## 2. Escalation

Increase tension.
Add unexpected information.

## 3. Payoff

Deliver the insight quickly.

## 4. Reframe

End with a new way to think.

# Hook Types That Usually Work

* “Nobody realizes…”
* “The scary part is…”
* “This changes everything…”
* “The real reason…”
* “This sounds insane but…”
* “People are missing the point about…”
* “This is secretly happening…”

# Retention Tricks

* Open loops
* Pattern interrupts
* Fast cuts
* Unexpected comparisons
* Escalating stakes
* Curiosity every 3–5 seconds
* Short sentences
* No long setup
